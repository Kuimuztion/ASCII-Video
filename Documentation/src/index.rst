源文件说明
==========

每个模块对应 src/ 中的一个 .c 文件，接口声明在 include/ 中同名的头文件里。下面按职责分组说明。

入口与命令行
------------

- main.c：程序入口。无参数且标准输入输出都是终端时进入界面，否则交给命令行。
- cli.c：解析命令行参数（``--play``、``--play-only``、``--mute``、``--block``、宽度与质量），输出用法说明并执行转换或播放。

探测、编码器与音频
------------------

- video.c：用 ffprobe 读取源视频的尺寸、帧率与旋转信息。``miku_choose_profile_ex`` 在档位基础上应用比例与显式帧率；比例首项为「自动铺满」（终端为手机或平板竖屏时对齐竖屏比例，电脑横屏终端全屏满铺，兼顾无黑边与不拉伸畸变），``9:16``、``3:4`` 竖屏比例与竖屏终端下以短边为基准生成竖屏分辨率（如 1080x1920、1080x1440）。
- encoder.c：编码器候选表；每个候选都真编几帧验证，只认能解出全部帧的编码器。还负责档位表、CPU 与内存预算、``WxH@FPS`` 解析，以及输出帧数检查和 BT.709 色标补写。
- audio.c：音频播放进程。优先 mpv，其次 ffplay；通过 IPC socket 读取播放位置，供音画同步使用。
- util.c：字符串与 shell 转义、子进程退出码、单调时钟、临时目录和数值夹取等通用工具。
- strbuf.c：可增长的输出缓冲，供界面绘制和终端帧构建使用。

转换管线
--------

- convert.c：转换主流程。启动 ffmpeg 解码与编码两个子进程，把每个源帧按时间映射为若干输出帧（升帧率时重复、降帧率时跳过）。目标为 9:16 竖屏或竖屏自动铺满且源视频为横屏时，解码管道自动应用 ``transpose=1`` 顺时针旋转 90 度并互换宽高布局，使横屏片源无黑边铺满竖屏视频。同时负责进度回调、取消、以及硬件编码失败后的软件重试。
- layout.c：计算字符网格在画布中的位置。字符高度为宽度的两倍，画面居中，四周留黑边。
- glyph.c：字形采样（缩小用面积平均，放大用双线性插值），并按墨量排序生成字符图集，用于把亮度映射为字符。
- font_data.c：内嵌的 16x32 位图字体，覆盖 95 个可打印 ASCII 字符，数据布局为 ``miku_font_bitmap[字形][行]``。
- render.c：把 RGB24 采样点渲染成字符格（字形混合、分离白底与色度的提亮防漂白），以及色块风格的渲染。字符风格带一份可选的跨帧状态：同时记录每格上一帧的字形与 RGB 颜色，候选字形墨量接近且色差在容忍范围内时直接跳过重绘，画面浓淡不变而体积更小、速度更快。

播放与终端输出
--------------

- playback.c：终端播放调度。用 ffmpeg 解码采样帧，检测到终端为手机竖屏（9:16，高大于宽）且源视频为横屏时，自动顺时针旋转 90 度（``transpose=1``）并全屏 100% 满铺当前可见行列，手机横屏手持即可宽屏观看；桌面宽屏全屏点对点铺满（不多填也不少填），按单调时钟显示有效帧并与音频时钟对齐；在 Kitty 终端播放时临时将当前窗口字号切换为设置大小（默认 6，支持 4.0~12.5 范围调节）以获得更高字符密度，正常结束、按 ``q`` 或收到退出信号时恢复用户默认字号与终端状态。
- terminal.c：查询终端列数与行数，失败时返回非正值，由调用方回退。
- terminal_frame.c：把渲染好的格子按行序列化为终端输出字节流，末行省略换行以防满屏滚屏，支持字符风格的跨帧字形稳定。

界面（ui_*）
------------

- ui.c：界面主状态机。配置页循环、已有视频页路由、设置页路由、点击与按键分派、开始转换或播放的动作路由，以及交互入口 ``miku_tui_main``。
- ui_terminal.c：终端生命周期（原始模式、备用屏、鼠标上报）与按键协议解析。鼠标松开和移动事件在这里被吞掉，上层只看到按下的点击。
- ui_home.c：首页，绘制标题、随机歌词与五个入口（视频转换、视频播放、已有视频、设置、退出）。
- ui_settings.c：设置页。支持直接使用方向键（←/→/↑/↓）在 4.0 到 12.5 之间选择 Kitty 播放字号（步长 0.5），数值持久化至配置目录的 ``settings.tsv``（``MIKU_CONFIG_DIR``，其次 ``$XDG_CONFIG_HOME/miku``，再退回 ``~/.config/miku``）。
- ui_library.c：已有视频库。负责在转换前按规格生成不互覆的输出路径，将已转换视频与当前目录成品按「视频名 + 规格」去重持久化到同一配置目录的 ``library.tsv``（记录存绝对路径，换工作目录也能找回），并在列表右侧展示规格、支持回车或点按直接在终端播放；终端过窄时先把规格收成「分辨率 + 风格」一行。
- ui_config.c：转换与播放的配置页，负责各配置项的显示、调整、字段编辑，以及由输入路径推导输出路径。
- ui_progress.c：转换进度页与完成页。绘制进度、轮询取消键、把 ffmpeg 错误重定向到日志，完成页等待用户选择。
- ui_picker.c：文件选择器。默认是内置单列列表：第 3 行常驻输入栏（边打边过滤，也可直接输路径回车进入，支持绝对路径、相对路径、`~/` 与 `..`），列表行可直接点击选定；只有设置 ``MIKU_PICKER=fzf`` 或 ``MIKU_PICKER=dialog`` 才改用外部工具。
- ui_picker_external.c：fzf 与 dialog 的适配，生成列表、调用外部程序并读取结果（同时取回 fzf 输入框内容，允许把路径当输入）。
- ui_directory.c：目录扫描与路径处理，给内置列表提供子目录与视频文件。
- ui_text.c：UTF-8 显示列宽计算、截断、居中与整行输出。
